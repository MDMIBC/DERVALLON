# DREVALLON review-build handoff

## Development and verification

From the managed project root, run `pnpm install`, `pnpm dev`, `pnpm exec vitest run`, `pnpm check` and `pnpm build`. The active managed preview is a static React/Vite site; no customer-facing backend or manufacturer connection is active. `tools/site_visual_qa.mjs` exercises the routes at phone, tablet, laptop and desktop widths. The portable copy, with all selected media included, is generated by `python3 tools/export_portable.py`; its own README has independent run instructions.

## User-facing preview flows

The homepage, six category routes (Suits, Shirts, Ties, Trousers, Blazers, Jackets), product presentations, search, About, Contact, account preview, information, Design Studio and custom-order wizard have responsive light/dark layouts. The visible homepage heading and collection links lead into these routes. Search/menu are focus-managed; motion respects reduced-motion preferences.

The Design Studio is a separate illustrative configuration journey. `/custom-order` is a **four-stage, frontend-only preview**: fabric, style, optional centimetre measurements, and a double-check review. It includes illustrated measuring guides, locally previewed reference photos with non-destructive browser crop/rotate controls, a visible progress indicator, editing links and acknowledgement before **Confirm preview**. Neither that button nor the Contact form sends a real order or enquiry.

Reference photos stay in memory for the open browser tab. **Save for Later** explicitly stores only selected options and measurement text in localStorage for up to seven days; it never stores photos and offers manual restore or deletion. Without clicking Save for Later, nothing is persisted. See `CUSTOM-ORDER-PREVIEW.md` for detailed privacy and validation behavior. There is no live account, payment, checkout, contact delivery, tailor verification or manufacturer API. Unverified social-platform links have been removed pending owner-provided official URLs.
